## Topology Visualization

### Hypergraph Structure Overview

The Boundary domain model forms a complex hypergraph where:

- **Nodes** represent resources (Scopes, Users, Targets, etc.)
- **Links** represent relationships (containment, membership, authorization, etc.)
- **Truth Values** (stv) indicate certainty and strength of relationships

### Key Relationship Patterns

1. **Hierarchical Containment**: Scopes contain other scopes and resources
2. **Membership**: Users belong to Groups, Hosts belong to HostSets
3. **Authorization**: Roles grant permissions through Grants
4. **Association**: Accounts link to Users, Credentials to Targets
5. **Session Flow**: Users connect to Targets via Sessions

## Knowledge Queries

Using OpenCog's pattern matching, you can query this topology:

```scheme
;; Find all resources contained in GlobalScope
(GetLink
  (TypedVariableLink
    (VariableNode "$resource")
    (TypeNode "ConceptNode"))
  (EvaluationLink
    (PredicateNode "containedIn")
    (ListLink
      (VariableNode "$resource")
      (ConceptNode "GlobalScope"))))

;; Find all authentication methods
(GetLink
  (TypedVariableLink
    (VariableNode "$method")
    (TypeNode "ConceptNode"))
  (InheritanceLink
    (VariableNode "$method")
    (ConceptNode "AuthMethod")))

;; Find what Users can access through Roles
(GetLink
  (VariableList
    (TypedVariableLink
      (VariableNode "$user")
      (TypeNode "ConceptNode"))
    (TypedVariableLink
      (VariableNode "$role")
      (TypeNode "ConceptNode")))
  (EvaluationLink
    (PredicateNode "assignedTo")
    (ListLink
      (VariableNode "$role")
      (VariableNode "$user"))))
```

## Benefits of OpenCog Representation

1. **Explicit Relationships**: All connections between concepts are formally defined
2. **Queryable Structure**: Pattern matching enables complex queries
3. **Extensible**: New concepts and relationships can be added without restructuring
4. **Reasoning**: Supports inference and deduction about domain model
5. **Truth Values**: Can represent uncertainty or confidence in relationships
6. **Hypergraph Flexibility**: Supports multi-way relationships beyond binary edges

## Integration Points
